# Olga — Scheda D&D

Scheda personaggio statica, responsive e installabile tramite GitHub Pages.

## Funzioni

- riepilogo rapido per il combattimento;
- contatore dei punti ferita;
- slot incantesimo interattivi;
- popup con descrizioni sintetiche degli incantesimi e dei tratti;
- filtri per livello;
- note di sessione e modifiche principali salvate in `localStorage`;
- nessun backend, account, cookie o servizio esterno.

## Nota sui dati

La prima versione è stata trascritta da fotografie della scheda cartacea. Le voci marcate **Da confermare** potrebbero richiedere correzioni. Le descrizioni sono promemoria sintetici per il tavolo e non sostituiscono il manuale/regolamento scelto dal DM.

## Sviluppo locale

```bash
python3 -m http.server 8080
```

Aprire `http://localhost:8080`.
